SafeStake: Decentralized Crowdfunding Platform

GitHub Documentation

A decentralized crowdfunding platform built on Ethereum that enables secure, milestone-based project funding with transparent governance. Implements smart contract-based escrow, decentralized milestone approval through random jury selection (Chainlink VRF), and automated fund release. Features factory pattern deployment of project-specific ERC-20 tokens, IPFS integration for decentralized document storage, and OpenZeppelin Governor contracts for secure governance.
